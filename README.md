# Single-Page HTML CV

A clean, semantic single-page Curriculum Vitae built purely with HTML as part of the [roadmap.sh Frontend Developer projects](https://roadmap.sh/projects/single-page-cv).

## Live Demo
- **GitHub Pages:** https://luckyirwansyahnatawijaya-ops.github.io/Single-Page-CV/

## Features Implemented
- **Semantic HTML5 Structure:** Uses `<main>`, `<header>`, `<address>`, `<section>`, and `<article>` tags for clear document hierarchy.
- **SEO Meta Tags:** Includes `description`, `keywords`, `author`, and `viewport` metadata in the `<head>`.
- **Open Graph (OG) Tags:** Configured for clean link previews when shared on social platforms.
- **Custom Favicon:** Linked monogram icon displayed in the browser tab.
